Plugin for reading a Wika pressure transmitter. 
Tested with a Wika P-30. 

Authors
=======

* Matthieu Guer  (m.guer@hw.ac.uk)



Instruments
===========

Below is the list of instruments included in this plugin

Viewer0D
++++++++

* **Wika**: control of a wika 0D detector



Installation instructions
=========================

* PyMoDAQ 5.1.0
* Tested on Windows 11

1. Install CP210xVCP (https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads). 
2. Install the pymodaq
3. Install the plugin
